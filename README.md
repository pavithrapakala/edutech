# Edutech Course Directory

This is a React application that displays a list of courses with filtering, sorting, and pagination.

## Features

* View courses in card layout
* Search by course name
* Filter by category and instructor
* Sort by name and rating
* Pagination with page size option
* Loading and error handling

## Tech Stack

* React (CRA)
* Material UI
* Axios
* MockAPI
